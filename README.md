# 超星作业答案转移（抄作业）助手 (Chaoxing Answer Transfer)

![访问量](https://count.getloli.com/get/@chaoxing-answer-transfer?theme=moebooru)

这是一个帮你在超星学习通上一键「抄作业」的轻量级浏览器脚本。

当一个人（账号 B）做完作业或考试后，可以通过脚本一键导出答案文件，发给另一个人（账号 A）导入并自动填报；也可以在同一台电脑的不同浏览器间，通过剪贴板一键将答案复制粘贴过来，自动完成题目比对并批量勾选填写。

## 主要特性

- **双场景流转**：优先支持同学间通过文件导出 / 导入一键抄作业，亦支持同一设备双浏览器剪贴板一键互填。
- **智能文本匹配**：题目按唯一题目 ID 对齐，客观题按选项文本比对，不受跨账号题目与选项字母（A/B/C/D）乱序影响。
- **题型全面支持**：支持单选、多选、判断，以及填空、简答等富文本主观题（自动保留段落格式）。
- **作答来源灵活**：支持已交卷详情页提取标准答案或历史作答，也支持未提交作答页提取当前临时作答。
- **安全预览与回填**：先预览匹配结果，无误后一键执行填写；不自动触发交卷，保留人工核验确认环节。

使用前需先安装浏览器脚本管理器（任选其一）：
- [Tampermonkey (油猴)](https://www.tampermonkey.net/)
- [ScriptCat (脚本猫)](https://scriptcat.org/)

安装脚本管理器后，点击下方链接安装本脚本：

👉 **[点击安装超星作业答案转移（抄作业）助手](https://raw.githubusercontent.com/heimenkyou/chaoxing-answer-transfer/main/chaoxing-answer-transfer.user.js)**  
国内网络访问较慢时，可改用 Gitee 镜像：[点此安装](https://gitee.com/heimenkyou/chaoxing-answer-transfer/raw/main/chaoxing-answer-transfer.user.js)

浏览器将自动弹出安装确认窗口，点击「安装」即可。如果是多台设备或两个浏览器配合使用，需要在各端分别安装此脚本。

> **更新说明**：如需更新，再次点击上方安装链接即可覆盖升级；已安装的脚本管理器也会依据 `@updateURL` 自动检测并提示新版本。

## 使用流程

### 如何呼出操作面板

安装脚本后，在超星作业或考试页面：
1. 点击浏览器右上角脚本管理器（油猴 / 脚本猫）的图标。
2. 在下拉菜单中点击 **「答案转移：显示 / 隐藏面板」** 即可呼出操作面板。
3. 面板支持拖拽移动；按键盘 `Esc` 键或点击面板右上角 `×` 可随时收起面板。

---

### 场景一：A 抄 B 的作业（文件导出与导入，最常用）

适用于同学之间互相传递答案，B 做完了作业，A 需要把 B 的答案自动填到自己的作业里：

#### 第一步：账号 B 导出答案文件（做完作业的人）
1. 账号 B 在浏览器中打开已经做完的作业页面：
   - 若作业已提交，打开作业详情页（可导出题目标准答案或自己的历史作答）；
   - 若作业尚未提交，直接打开正在作答的页面（可导出当前页面已选好的作答）。
2. 点击脚本管理器图标呼出面板，点击 **「导出文件」**（未提交作答页显示为 **「导出本页作答」**）。
3. 浏览器将自动下载一个以作业名称命名的 JSON 文件（例如 `作业三-正确答案-20261121.json`）。
4. 账号 B 将下载好的 JSON 文件通过聊天工具发送给账号 A。

#### 第二步：账号 A 导入文件一键填报（抄作业的人）
1. 账号 A 在浏览器中打开同一份作业的作答页面。
2. 点击脚本管理器图标呼出面板，点击面板上的 **「导入文件」** 按钮，选择收到 JSON 文件。
3. 导入后面板将自动解析并在下方列表中展示每道题的匹配预览状态。
4. 核对无误后，点击 **「执行填写」**，脚本将自动批量勾选选项并回写填空与简答内容。
5. 检查页面填报无误后，账号 A 手动点击超星页面原生的「提交」按钮完成交卷。

---

### 场景二：同一设备双浏览器（剪贴板一键互填）

适用于同一台电脑上登录了两个账号（例如 Chrome 登录已完成的账号，Edge 登录待填写的账号）：

1. **源账号复制答案**：
   - 在已完成的作业页面呼出面板，点击 **「复制正确答案」**（或「复制我的答案」/「复制本页作答」），答案数据将自动存入系统剪贴板。
2. **目标账号粘贴填报**：
   - 切换至另一个浏览器的作业作答页面，呼出面板。
   - 在面板输入框中直接按 `Ctrl+V` 粘贴刚才复制的内容。
   - 点击 **「预览匹配」** 核对各题匹配状态。
   - 确认无误后点击 **「执行填写」**，脚本将自动完成选项勾选与文本回填。
   - 检查无误后，手动点击超星页面的「提交」按钮交卷。

---

### 考试场景特别说明

超星考试默认使用逐题作答视图（一题一页），脚本仅支持在**整卷预览**视图下提取与回填：
- 进入考试后，需先点击页面右上角的「整卷预览」切换为完整试卷视图，方可呼出面板进行导出或填报。
- 若以另一账号的考试作为答案源，同样需先在那边进入「整卷预览」。已交卷且允许查看答案的考试可提取标准答案；若不允许查看答案，则仅能在交卷前提取当前已选作答。

## 界面功能与按钮说明

| 操作按钮 | 适用页面 | 功能说明 |
| --- | --- | --- |
| 导出文件 / 导出本页作答 | 所有支持页面 | 将当前解析到的答案数据导出为 JSON 文件下载，文件名默认采用作业标题 |
| 导入文件 | 作答页、整卷预览页 | 读取本地导出的 JSON 答案文件，自动填入输入框并触发匹配预览 |
| 复制正确答案 | 已提交的作业详情页 | 提取题目标准答案至剪贴板；若某题未公布正确答案，则退回提取该账号的历史作答 |
| 复制我的答案 | 已提交的作业详情页 | 仅提取该账号的历史作答至剪贴板，不核对对错 |
| 复制本页作答 | 作答页、整卷预览页 | 提取当前页面已选中的选项及输入的文字内容至剪贴板，用于未提交时的作答迁移 |
| 预览匹配 | 作答页、整卷预览页 | 仅比对题目与选项文本，展示匹配结果与原因，不修改页面内容 |
| 执行填写 | 作答页、整卷预览页 | 根据比对结果批量勾选选项并填入文本，完成后自动重查并刷新状态 |

面板下方展示逐题比对列表，状态符号说明：
- `✓`：提取到答案或成功匹配到当前页面选项。
- `!` / `?`：选项文本部分匹配或未完全对齐，需人工核对。
- `×`：当前页面缺少对应题目、题型不兼容或匹配失败。
- 点击列表中的任意题目行，页面将自动平滑滚动至对应题目位置。

## 题目匹配与对齐规则

超星同一份作业在不同账号下，题目顺序与选项字母通常会被随机打乱。脚本采用如下对齐策略实现准确回填：

- **题目对齐**：优先依据题目节点的唯一 `data` 属性（题目 ID）进行跨账号对齐；若某题缺失 ID，则退回至去除空白与标点后的题干文本进行比对。
- **客观题对齐**：忽略随机变动的选项字母（A/B/C/D），直接比对选项文本内容。优先进行全文本精确匹配；若存在格式差异，则依次回退至去除标点比对与双向包含匹配。
- **判断题对齐**：对常见正反表述（`对 / 正确 / √ / true` 与 `错 / 错误 / × / false`）进行归一化后比对。
- **主观题（填空/简答）**：按照空位顺序依次填入，富文本编辑器（UEditor）内保留原有 HTML 段落格式，并同步回写底层的 `textarea` 字段。
- **作答状态判定**：单选与判断题以 `check_answer` 类名识别选中状态，多选题以 `check_answer_dx` 类名识别（考试页面中的 `aria-checked` 属性在切换选项后存在残留，不作为选中依据）。

## 使用限制与注意事项

1. **单页加载限制**：对于分页加载的作业或考试，脚本仅能提取和填写当前页面已加载渲染的题目。
2. **考试视图限制**：超星考试必须切换为「整卷预览」视图，逐题作答视图因每次仅渲染单道题，脚本不予处理。
3. **复合题型限制**：资料题、复合问答题等特殊嵌套题型未经充分实测，建议手动确认作答。
4. **安全提示**：脚本仅辅助完成选项勾选与内容填充，**不会自动触发最终提交**。填写完成后请务必人工通览核对，确认无误后再手动交卷。
